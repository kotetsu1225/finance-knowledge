# ALTERNA 学習

三井物産デジタル・アセットマネジメント株式会社（以下 MDM）が提供する資産運用サービス「ALTERNA（オルタナ）」について、
**事業モデル・金融/アセットマネジメントの基礎・関連法律・税制**を、一次資料に基づいて完全理解するための学習リポジトリ。

## 学習ルール

1. 一次資料（目論見書、条文、公式発表、国税庁資料など）の**原文を引用し、出典（URL・ページ）を明記**する
2. 推測で書かない。確認できていないことは `questions.md` に「問い」として積む
3. 1トピック = 1ノート（`notes/phaseN/NN-topic.md`）
4. フェーズは「完了条件」を満たしてから次へ進む

## 構成

| ファイル | 役割 |
|---|---|
| `roadmap.md` | Phase 0〜5 の内容と完了条件（地図） |
| `progress.md` | 現在地・次にやること（セーブデータ） |
| `questions.md` | 今は扱わない問いの置き場（駐車場） |
| `glossary.md` | 用語集（原文・出典付き） |
| `sources.md` | 一次資料リスト |
| `notes/` | 学習ノート本体 |
| `PROJECT_INSTRUCTIONS.md` | Claudeプロジェクトに貼る指示文 |

## 1セッションの進め方

1. **開始**：Claudeプロジェクトで新しいチャットを開き、`progress.md` の「次回やること」を1つだけ指定する
2. **学習**：脱線しそうな疑問は深追いせず `questions.md` に積む
3. **締め**：Claudeが `notes/_template.md` の形式でノートを出力 → コミット → `progress.md` 更新 → プロジェクトナレッジを最新版に差し替え
