# finance-knowledge

金融・資産運用・関連法律・税制について、一次資料に基づいて学んだことを蓄積するリポジトリ。

## 共通ルール
1. 一次資料（目論見書、条文、公式発表、国税庁資料など）の**原文を引用し、出典（URL・ページ）を明記**する
2. 推測で書かない。確認できていないことは各テーマの `questions.md` に「問い」として積む
3. 1トピック = 1ノート
